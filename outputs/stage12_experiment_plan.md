# ResNet18学习率对照实验设计

日期：2026-10-07（Asia/Shanghai）

## 实验目的

在同一适配ResNet18、同一数据划分和相同5轮训练下，把Adam学习率从0.001降到0.0003，会怎样影响学习过程与验证集分类表现？

实验变量为学习率0.001与0.0003，其余条件一致。

## 两组设置

| 项目 | A组 | B组 |
| --- | --- | --- |
| 模型 | 适配CIFAR-10的ResNet18 | 相同 |
| 学习率 | 0.001 | 0.0003 |
| 优化器 | 新建Adam | 独立的新建Adam |
| 初始化 | 同一份新随机初始化参数及BatchNorm统计 | 复制相同初始数值 |
| 数据 | 固定40000训练、10000验证 | 相同索引 |
| 图片变换 | ToTensor，无增强、无Normalize | 相同 |
| batch size | 8 | 8 |
| 训练轮数 | 5 | 5 |
| 每轮更新数 | 预期5000，运行时实际记录 | 相同 |
| 总更新数 | 预期25000，运行时实际记录 | 相同 |
| 随机设置 | 初始化seed42，独立shuffle Generator seed43 | 相同起点与逐轮图片顺序 |
| 最好模型选择 | 最高验证accuracy，同分保留较早轮 | 相同 |

脚本先运行A组5轮，再运行B组5轮。每组都会重新创建模型和优化器，并复制同一初始状态；B组不会从A训练后的参数继续训练。

## 更新机制与控制条件

学习率控制优化器调整参数的步幅。在梯度和Adam内部状态相同的某一步，0.0003对应0.001的30%更新幅度。训练继续后，两组参数、梯度和内部状态会走向不同轨迹，不能把整个训练过程或最终参数简单看成乘0.3。

两组的图片数、批次数和轮数相同，所以更新次数相同。较小的学习率可能让学习过程更平缓，也可能让5轮内的学习进展较慢；本次没有预先确定哪个组更好。

输入与输出仍是images=[B,3,32,32]、labels=[B]、logits=[B,10]、loss为标量。改变学习率不会改变这些shape。

## 运行后怎样比较

首先比较各组最高验证accuracy及其所在轮次；同时看各轮验证accuracy/loss和训练accuracy，分析两组学习过程。记录实际更新数和训练耗时，保留完整条件。单次实验结论限定于本次配置，不据此确定普遍最优学习率。

已有阶段10的81.37%作为历史参考保存；本次A、B两组都从新的共同初始化开始训练，主要比较本次两组的实际结果。

实际run=stage12_lr_20261007_195820_358131，两组各5轮/25000次更新，best均第5轮。A验证accuracy=81.37%、loss=0.569245707；B验证accuracy=82.46%、loss=0.525009159。B高1.09个百分点、多正确109张验证图片。训练accuracy分别92.3975%与93.9575%，平均每轮训练分别66.373930秒与65.700836秒。B五轮验证accuracy均高于A，验证loss均低于A。

结论限于本次CIFAR-10、适配ResNet18、固定划分、共同初始化及5轮预算。更换模型或训练预算后，需要对应的对照证据。完整结论见[实验结论](stage12_lr_20261007_195820_358131/experiment_conclusion.md)。
